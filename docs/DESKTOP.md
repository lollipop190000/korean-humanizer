# Windows에서 글을 넣고 다듬기

[Windows 설치 파일 다운로드](https://github.com/lollipop190000/korean-humanizer/releases/download/desktop-v0.2.0/Korean-Humanizer-Windows.zip)

## 처음 한 번

1. ZIP을 다운로드하고 **전체 압축을 풉니다**. ZIP 안에서 바로 실행하지 마세요.
2. `Korean-Humanizer` 폴더의 **`Install.cmd`를 더블클릭**합니다.
3. Python과 추론 패키지 설치가 끝날 때까지 창을 열어 둡니다. 바탕화면에 `Korean Humanizer`
   바로가기가 생기고 브라우저에 글 입력 화면이 열립니다.
4. 글을 입력하고 **글 다듬기**를 누릅니다. 첫 실행에는 기반 모델과 실제 학습 어댑터를
   다운로드하고 불러오므로 시간이 걸립니다. 이후에는 같은 모델을 재사용합니다.

결과 옆 **결과 복사**로 다른 프로그램에 붙여 넣을 수 있습니다.
다음부터는 바탕화면 바로가기만 실행하면 됩니다. 브라우저 화면을 닫아도 실행 창이 열려 있으면
앱은 남아 있습니다. 끝낼 때는 실행 창에서 Ctrl+C를 누르거나 창을 닫으세요.
이미 켜진 상태에서 바로가기를 다시 누르면 같은 앱의 화면을 엽니다.

## 사양과 설치 위치

- Windows 10/11 64비트, 여유 디스크 25GB, NVIDIA GPU 권장.
- **RAM 32GB + RTX 4070 Laptop(일반적으로 VRAM 8GB)**: 자동 NF4 메모리 절약 모드를 사용합니다.
- GPU 메모리 12GiB 이상에서는 원래 정밀도, 미만에서는 4비트를 선택합니다. NVIDIA 드라이버는
  PyTorch CUDA 12.4와 호환돼야 합니다. GPU가 있는데 감지되지 않으면 드라이버를 업데이트한 뒤 다시 설치하세요.
- CPU도 실행 가능하지만 RAM 32GB 이상을 권장하며 훨씬 느립니다. 이 Windows 설치기는 AMD GPU 가속을 구성하지 않습니다.
- 설치 위치: `%LOCALAPPDATA%\KoreanHumanizer`. 관리자 권한이나 시스템 Python 변경은 필요 없습니다.
- 모델 캐시: 같은 폴더의 `model-cache`, 어댑터: `app\artifacts\models\nikl-practical-001`.

이 프로그램은 모델 전체를 ZIP에 넣지 않고, 첫 실행에 고정 기반 모델과 학습 어댑터를 받습니다.
어댑터 파일은 크기와 SHA-256으로 검증하며, 받지 못하면 원래 Qwen으로 대체하지 않고 중단합니다.
인터넷은 설치·모델 다운로드에 사용합니다. 입력/출력은 로컬에서 처리하고 자동 파일 저장하지 않습니다.

## 잘 안 될 때

- 설치 오류: 실행 창의 메시지를 확인하고 `Install.cmd`를 다시 실행합니다. 모델 캐시는 유지됩니다.
- 방화벽으로 다운로드 실패: GitHub/Hugging Face/PyPI/PyTorch 다운로드 접근이 필요합니다.
- GPU 메모리 부족: 게임 등 GPU를 쓰는 앱을 닫고 재실행하세요. 짧은 문단부터 시도합니다.
- 입력 길이 오류: 문단별로 나누세요. 최대 입력은 프롬프트 포함 2,048토큰입니다.
- 결과가 잘림: 한 번의 출력 상한은 512토큰입니다. 입력을 더 짧게 나눠 주세요.
- 삭제: 실행 창을 닫은 후 `%LOCALAPPDATA%\KoreanHumanizer` 폴더와 바탕화면 바로가기를 지웁니다.

기계 검사를 통과해도 의미·부정·조건·숫자가 달라질 수 있으니 결과를 읽어 확인하세요.
NF4 양자화는 메모리를 줄이는 실행 옵션이며 재학습이 아닙니다. 원래 BF16 연구 비교와 동일한
출력이나 품질을 보장하지 않습니다.

## 검증 범위

CPU 테스트와 합성 입력의 화면 흐름을 검사하고, 실제 Windows CI에서 설치 및 로컬 서버 시작을
확인합니다. 사용자의 실제 Windows GPU에서 모델을 생성하는 검증은 설치 후 처음 실행할 때 필요합니다.
`-ToolsOnly` 설치 옵션은 개발/CI 전용이며 추론 패키지를 설치하지 않으므로 일반 사용자는 쓰지 마세요.

소스에서 직접 실행하려면 [PC 설치](INSTALL.md)의 추론 환경을 준비한 뒤
Windows에서 `.venv-inference/Scripts/python.exe scripts/run_desktop.py`를 실행합니다.
