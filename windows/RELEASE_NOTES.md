같은 학습 모델에 **적극 재작성 (실험)** 모드를 추가한 앱 업데이트입니다.
새로 학습한 모델이나 품질 개선이 검증된 모델 버전은 아닙니다.

기존 실행 창을 닫고 ZIP을 전체 압축 해제한 뒤 `Install.cmd`를 실행하세요.
화면 하단의 Windows 앱 v0.4.0을 확인하세요. 모델 캐시는 유지됩니다.

- 기본 선택인 적극 재작성은 어순·문장 구조 변경을 요청하고 sampling을 사용합니다.
- 기본 다듬기를 선택하면 이전 버전의 지시문과 greedy 생성으로 실행합니다.
- 최대 50,000자/256구간 자동 처리, 진행률, 잘림 재분할, 변경 없음 표시를 유지합니다.
- 길어진 지시문을 구간 토큰 수에 포함하고, 재시도에도 선택한 모드를 적용합니다.
- 글자 수를 넘는 붙여넣기는 조용히 자르지 않고 오류를 표시합니다.

현재 모델의 실제 학습쌍은 많은 경우 서로 비슷했습니다. 새 모드의 실제 GPU 출력과 품질은 아직
검증하지 않았습니다. 문장이 달라져도 주체·조건·부정·사실이 유지됐는지 확인해야 합니다.
