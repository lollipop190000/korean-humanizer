# 개발 평가 입력

`dev_seed.v1.jsonl`은 이 프로젝트에서 AI가 새로 작성한 한국어 개발용 입력 72개입니다.
6개 장르에 12개씩 배치했고, 최소 수정 기대 입력과 재작성 기대 입력을 함께 넣었습니다.
사람 원문·학습 정답·독립 holdout이 아닙니다. 여러 외부 모델의 실제 초안 분포를 대표하지도 않습니다.
현재 review_status=draft이며 사람 검토 후에만 human_reviewed와 review_ref를 기록할 수 있습니다.

텍스트 속 인물·기관·수치·사건은 평가를 위한 가상 설정입니다. 문장에 대한 외부 사실 검증이 아니라
입력의 주장·불확실성·어투를 출력에서 보존하는지 평가합니다.
`invariants`는 사람 평가자를 위한 의미 보존 기준입니다. 모델 요청에는 포함하지 않습니다.
이 자료의 공개는 소프트웨어 개발용 합성 fixture 공개에 해당합니다. 실제 코퍼스는 이 폴더에 넣지 않습니다.

검토 순서:
1. 입력만 보고 genre, expected_edit, invariants가 타당한지 확인합니다.
2. 잘못된 문장/수치/보호 span을 수정하고 데이터 버전을 올립니다.
3. 검토자와 기록 위치를 review_ref에 연결합니다.
4. 모델 비교 전에 데이터/프롬프트/설정 해시를 고정합니다.
5. 실제 여러 생성 모델의 초안과 인간 글은 별도 권한 확인·검수를 거쳐 추가합니다.

현재 입력은 모델 성능 보고에 충분한 검증된 평가셋이 아닙니다. 빠른 오류 발견과 실행 준비에 사용합니다.

`dev_challenge.v1.jsonl`은 첫 GPU 결과를 보고 보완한 AI 작성 초안 24개입니다.
동일 사실을 담은 자연스러운/어색한 문장 12쌍이며 같은 group_id로 묶었습니다.
기존 선택 문항 12개와 합친 36개가 prompt-study-002의 입력입니다.
`prompt_study.v1.rubric.jsonl`에는 그 36개에 대한 명제 120개와 편집 검토 기준이 있습니다.
이 기준은 모델에 보내지 않으며, 블라인드 검수자는 조건 이름·기대 수정 라벨을 보지 않습니다.
자세한 실험 계약과 사람 검수 필요 사항은 docs/USAGE.md에 있습니다.
