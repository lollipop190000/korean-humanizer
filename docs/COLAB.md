# Google Colab에서 시작하기

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/lollipop190000/korean-humanizer/blob/main/notebooks/quickstart.ipynb)

1. 위 버튼으로 노트북을 열고 필요한 경우 자신의 Drive에 사본을 저장합니다.
2. 기본 CPU 런타임에서 1~3번 셀을 실행합니다. 설치, 합성 자료 검증, mock 파이프라인과
   추론 dry-run을 확인할 수 있습니다. API 키나 GPU, 실제 코퍼스가 필요하지 않습니다.
3. 실제 학습 모델 추론이 필요하면 런타임 유형을 GPU로 바꾸고 기본 셀을 다시 실행합니다.
4. 선택 추론 부분의 `RUN_MODEL`을 `True`로 바꾸고 셀을 실행합니다. 모델 다운로드와
   추론 의존성 설치에는 수 GB 디스크와 시간이 필요합니다. Colab의 GPU 제공량/사용 한도는
   계정과 시점에 따라 달라지며 유료 플랜이 필수는 아닙니다.

기본 설정은 **Qwen3-4B + 프로젝트의 학습된 어댑터**입니다. 공개 릴리스에서
어댑터를 자동 다운로드하고 해시를 검증한 뒤 적용합니다. 파일이 없거나 다르면 중단합니다.
원래 Qwen3-4B만 비교하려면 `USE_BASE_ONLY = True`로 명시합니다.
직접 보유한 동일 기반 모델용 LoRA 어댑터는 Colab 파일 패널로 폴더를 준비한 다음
`ADAPTER_DIR`에 경로를 지정합니다. 기본 프로젝트 모델은 경로 지정이 필요 없습니다. 노트북이 Drive 전체를 자동 마운트하지는 않습니다.
모델 가중치나 원문을 GitHub에 올릴 필요가 없습니다.

T4는 이 추론 예제에서 FP16을 사용합니다. 별도 BF16 학습 실행기는 T4에서 지원되지
않으므로 이 노트북을 학습 실행으로 혼동하지 마세요. 긴 입력은 메모리 부족을 일으킬 수
있습니다. 기본 출력은 256토큰이며 입력 한도는 프롬프트 포함 2,048토큰입니다.

노트북 기본 CPU 셀은 Linux Python 3.11 환경에서 실행 확인합니다. 실제 Colab GPU에서
모델을 생성한 검증은 아직 하지 않았습니다. 설치/드라이버 문제는 [PC 안내](INSTALL.md)를
함께 참고하세요.

Colab 파일은 런타임 종료 시 사라질 수 있습니다. 필요한 결과만 파일 패널에서 내려받으세요.
입력과 출력이 노트북에 저장될 수 있으므로 공유하기 전 실제 원문과 실행 출력을 지우세요.
공개 저장소의 노트북에는 실행 출력·키·실제 학습 자료를 포함하지 않습니다.
