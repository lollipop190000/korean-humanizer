# 평가 계획 v0.1

상태: 방법과 루브릭의 초기 고정안. 실제 모델 비교 전 버전/해시를 확정합니다.
현재 `tests/fixtures/evaluation_cases.jsonl`의 12개 예시는 AI 생성 설계 예시이며 실제 holdout이 아닙니다.
후속으로 `eval/dev_seed.v1.jsonl`에 72개 AI 작성 개발 초안을 추가했습니다. 6개 장르 각 12개이며
최소 수정 기대 18개, 재작성 기대 54개입니다. 사람 검수 전이며 실제 외부 생성 모델의 분포나 독립 평가셋을 대체하지 않습니다.

## 평가 자료

- 개발셋 60~100 입력: 보고서/설명문/메일/수필·감상문/게시글/공식 문서.
- 최종 holdout 200~300 입력: 독립 원문·작성자·출처 그룹으로 분리하고 개발자가 튜닝에 사용하지 않습니다.
- 개발/최종 수량과 장르별 배분은 평가자의 실제 작업량을 산정한 뒤 결과를 보기 전에 확정합니다.
- 학습에 쓰지 않은 생성 모델의 초안, 자연스러운 글, 필요한 대조/부정/조건,
  혼합문·긴 문서·형식 정보를 포함합니다. 모델 생성 예시는 사람 글로 표시하지 않습니다.
- 자료 접근권한과 해시를 기록합니다. 평가 후 그 사례로 재학습하면 해당 셋은 개발 자료가 됩니다.

## 루브릭

| 축 | 판정 | 예시 |
|---|---|---|
| 자연스러움 | A/B/동률/평가불가 | 장르에 맞게 읽히는지, 기계적 반복·억지 구어체가 있는지 |
| 중대한 사실 변형 | 출력별 있음/없음 | 부정 반전, 가능→확정, 수치·주체·조건 변경, 정보 추가/누락 |
| 어투 이탈 | 출력별 있음/없음 | 존댓말→반말, 객관 보고→개인 주장, 없던 감정·비속어 추가 |
| 수정 적절성 | 별도 메모/실패 유형 | 이미 좋은 문장 과수정, 필요한 구문 삭제, 수정 부족 |
| 형식·보호 정보 | 기계검사 + 사람 확인 | 인용·코드·단위·고유명사·목록 유지 |

사실 판정은 실제 입력 초안과 출력을 비교합니다. 학습 원문만을 유일한 의미 정답으로 보지 않습니다.
숫자가 동일해도 수치와 대상의 연결이 바뀌면 오류입니다. 기계 검사는 이것을 보장하지 않습니다.
"효과가 있을 수 있다"→"효과가 있다"는 의미 오류입니다.
"A가 아니라 B를 사용해야 한다"의 필요한 대조를 지우면 실패입니다.
AI 특유 표현의 등장 횟수는 관찰용이며 금지 규칙이 아닙니다.

## 비교와 통계

원본 Humanizer, 강한 범용 LLM+프롬프트, 후보 베이스 모델, 학습 모델, identity를 개발 단계에서 비교합니다.
원본 모델은 공식 프롬프트/샘플링을 우선 사용하고 설정 차이를 공개합니다.
최종 후보·설정은 holdout 실행 전에 고정합니다. 예산에 맞춰 최종 비교 대상을 사전 확정합니다.
입력별 후보 수와 선택 방법을 고정하며 best-of-N 사례를 단일 출력 성능과 혼합하지 않습니다.

블라인드 자료는 A/B 위치와 항목 순서를 무작위화하고 정답 매핑은 평가자에게 전달하지 않습니다.
가능하면 두 평가자가 일부 공통 자료를 채점하여 일치도를 확인하고 불일치를 재검토합니다.
반복 평가/동일 원문 변형본은 독립 표본으로 세지 않습니다. 최종 분석은 문서 그룹 단위 부트스트랩 등으로 합니다.
현재 CLI는 기술 통계와 단일 평점/항목일 때 Wilson 구간만 제공합니다. 최종 통계 분석의 대체물이 아닙니다.
동률·평가불가·미평가 수, 사실 오류, 어투 이탈, 장르별 성능을 따로 보고합니다.

## 통과 판단의 초기 규칙

자연스러움의 우위와 사실/어투 악화 여부를 함께 판단합니다. 단순 승률 50% 초과만으로 성공 선언하지 않습니다.
의미 오류의 허용 수준과 비열등성 여유는 실제 사용 범위·검수 방식에 따라 최종 평가 전 확정해야 합니다.
그 값이 미정인 상태에서는 배포 준비 완료라고 표현하지 않습니다. 중대한 오류는 원인과 빈도를 모두 보고합니다.
소표본에서 오류가 없었다는 사실은 무오류 보장이 아닙니다. 탐지기 성적은 출시 판정에 사용하지 않습니다.

## 기계 지표의 범위

현재 구현: 숫자/일부 단위, 영문/한자, 코드/수식/인용, 지정 span의 누락·추가·변경 검사.
미구현: 형태소/POS/종결어미 분포, 고유명사 추출, 의미 판정, 문서별 군집 통계.
형태소 분석기는 후보 라이선스·Python 호환성·정확도를 검토한 뒤 Task 3에서 추가합니다.
