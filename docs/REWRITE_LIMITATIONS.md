# 학습 단위와 재작성 성능의 현재 근거

## 실제 학습 단위와 방향

nikl-practical-001은 문장 하나씩이 아니라 200~600자의 원문 발췌를 정답으로 학습했습니다.
train 2,000개 원문 길이 중앙값은 520자이며 입력 길이 중앙값은 524자였습니다.
사람 원문을 AI로 변형한 입력에서 원래 사람 글을 복원하는 방향입니다.

실제 제출한 학습 번들의 해시와 train pair ID를 대조해 집계했습니다. 원문은 이 문서에 공개하지 않습니다.

| train 구성 | 개수 | 입력과 정답의 차이 |
|---|---:|---|
| 자연문 유지 예제 | 200 | 모두 정확히 동일 |
| AI 변형 → 사람 원문 | 1,800 | 공백 제외 문자 유사도 중앙값 93.9% |

변형 쌍 1,800개 중 1,194개는 문자 유사도 90% 이상, 786개는 95% 이상이었습니다.
80% 미만은 171개였습니다. 이는 `difflib.SequenceMatcher(autojunk=False).ratio()`의 결과이며,
의미나 품질 점수, 복사한 글자 비율로 해석하지 않습니다. 크게 다시 쓴 예제보다 작은 수정에
가까운 예제가 많다는 진단 근거이며, 이것만으로 원인을 확정하거나 의미 보존을 판정하지 않습니다.

학습 데이터는 자동 검사 후 연구용 pending 상태로 사용됐으며 사람의 의미 검수가 완료된 데이터가 아닙니다.
1,000스텝 학습 완료 및 개발 손실 감소와 실용적인 재작성 품질 향상은 별개의 사실입니다.

## 저장된 모델 출력

이전 합성 개발 입력 72개 중 학습 어댑터의 출력이 원문과 다른 것은 20개,
공백 차이를 제외하면 15개였습니다. 이 평가는 보존 검사 위주이며 독립적인 재작성 품질 평가가 아닙니다.
원문을 거의 그대로 반환한다는 사용자 관찰을 단순히 좋은 입력이기 때문이라고 결론 내릴 수 없습니다.

## 앱 v0.4.0과 다음 학습 버전의 구분

앱의 적극 재작성 모드는 같은 가중치에 다른 지시문과 sampling을 적용하는 실험입니다.
가중치를 새로 학습한 버전이나 재작성 품질이 검증된 해결책으로 소개하지 않습니다.
기존 결과는 BF16 환경이었고 로컬 8GB GPU는 NF4를 사용하므로 조건도 다릅니다.

다음 학습을 시작하기 전에는 구조가 충분히 다른 입력/정답 쌍을 확보하고 의미 보존을 검토해야 합니다.
문자 차이를 키우는 것만으로 선별하면 삭제·환각·사실 변경을 좋은 재작성으로 오인할 수 있습니다.
학습에 쓰지 않은 재작성 필요 입력과 자연문 유지 입력을 분리해 평가하고, 기존 모델과 같은 조건으로
비교해 사람의 의미·자연스러움·재작성 폭 평가를 확인해야 합니다. 이 문서는 재학습 완료 보고가 아닙니다.
