Windows용 Korean Humanizer 설치 묶음입니다. 압축을 푼 뒤 `Install.cmd`를 실행하세요.
설치가 끝나면 바탕화면의 `Korean Humanizer` 바로가기로 글 입력·다듬기·결과 복사 화면을 엽니다.

- 실제 1,000스텝 학습한 nikl-practical-001 어댑터를 자동 다운로드·검증·적용합니다.
- NVIDIA GPU를 감지해 CUDA를 설치합니다. VRAM 12GiB 미만에서는 NF4 메모리 절약 모드를 자동 사용합니다.
- 입력과 결과는 내 컴퓨터에서 처리하며 외부 추론 서버로 전송하지 않습니다.
- 관리자 권한이나 Git/Python 사전 설치가 필요 없습니다. 첫 설치와 모델 다운로드에는 인터넷과 여유 디스크 25GB가 필요합니다.
- 모델은 첫 다듬기 때 불러오고 다음 요청부터 재사용합니다. 실행 창을 닫으면 종료됩니다.

Windows CI에서 설치·브라우저 서버 시작을 검증합니다. GPU 생성은 해당 Windows PC에서 아직 검증하지 않았습니다.
NF4 출력은 원래 BF16 비교 결과와 다를 수 있으므로 숫자·의미·어투를 직접 확인하세요.

앱 코드와 학습 추가 가중치는 MIT, 기반 Qwen3-4B/토크나이저와 의존성은 각각의 라이선스를 따릅니다.
